# 銘柄ノート（スタンドアロン版）

日本株の「①見た銘柄の閲覧履歴 ②株主優待とその条件 ③過去5年の株価チャート」をまとめて見られる、ブラウザだけで動くシンプルなアプリです。

- サーバーやアカウント登録は不要。**このURLを開くだけ**で使えます。
- データ（登録した銘柄・閲覧履歴・優待メモ）は、**開いている端末のブラウザの中だけ**に保存されます。あなたと友人が同じURLを開いても、データは別々になります（ブラウザのlocalStorageを使っているため）。
- 株価・5年チャートの取得だけは外部API（Yahoo Finance）を使うため、CORS制限を避ける小さな中継サーバー（Cloudflare Worker、無料）が別途必要です。中継サーバーを設定しなくても、銘柄の登録・閲覧履歴・優待メモ入力は問題なく使えます。

## 1. GitHub Pagesで公開する

1. このリポジトリをGitHubにpushする（すでにpush済みならスキップ）。
2. GitHubのリポジトリ画面 → **Settings → Pages** を開く。
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/(root)` に設定して **Save**。
4. 数十秒〜数分待つと、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリが公開される。
5. このURLを友人に送るだけで、友人もすぐ使い始められる。

## 2. 株価・チャート用の中継サーバー（Cloudflare Worker）を用意する

Yahoo Financeのデータはブラウザから直接取得できない（CORSでブロックされる）ため、`worker/worker.js` を **Cloudflare Workers**（無料枠で十分）にデプロイして中継させます。

1. https://dash.cloudflare.com/ で無料アカウントを作成してログイン。
2. 左メニューから **Workers & Pages → Create → Create Worker** を選択。
3. 名前を適当に付けて（例: `kabu-note-proxy`）作成。
4. エディタ画面が開いたら、デフォルトのコードを全部消して、このリポジトリの `worker/worker.js` の中身を丸ごと貼り付ける。
5. **Deploy** をクリック。デプロイが終わると `https://kabu-note-proxy.<あなたのサブドメイン>.workers.dev` のようなURLが発行される。
6. アプリ（GitHub Pagesで公開したページ）を開き、右上の ⚙️「設定」から、そのURLを「中継サーバーのURL」欄に貼り付けて保存する。

これで「株価を更新」「チャートを表示」「銘柄コード/企業名検索」が使えるようになります。**この設定は各端末・各ブラウザごとに1回だけ**必要です（友人にもURLを伝えて、友人の端末でも同じ設定をしてもらってください）。

> すでにWorkerをデプロイ済みの場合、検索機能（`/search`）を使うには `worker/worker.js` の最新版をCloudflareのエディタに貼り直して再Deployしてください（設定画面のURLは変わりません）。

## 3. 友人に渡すもの

- GitHub PagesのURL（アプリ本体）
- Cloudflare WorkerのURL（設定画面に貼ってもらう用）※あなたが1つデプロイして両方で共有してもOK。中身は誰の情報も保存しない単純な中継なので、共有しても問題ありません。

## できること

- **銘柄の追加**: 証券コード（4桁）または企業名で検索して候補から選ぶか、直接コード・銘柄名を入力する。検索は中継サーバー経由でYahoo Financeの検索APIを使うため、事前に「設定」でURLの登録が必要（未設定でも直接入力で追加は可能）。日本語の漢字社名は検索精度が落ちやすく、コードや英語名（例: `Toyota`）のほうが確実にヒットします。
- **閲覧履歴**: 銘柄の詳細ページを開くたびに自動で日時が記録されます（アプリ内のJavaScriptが記録するだけで、外部送信はしません）。
- **株主優待**: 必要株数（新規追加時は100株をデフォルトで自動入力。2018年の単元株制度統一以降、東証銘柄はほぼ100株単位ですが例外もあるため要確認）・権利確定月・内容を自由入力できるほか、みんかぶ・Yahoo!ファイナンス・Google検索へのショートカットリンクも表示されます。優待の内容そのものを自動取得しないのは、各社の優待情報サイトのスクレイピングが利用規約違反やサイト構造変化での破損リスクが高いためです（無料の公式APIは存在しません）。
- **過去5年チャート**: ボタンを押すとその場でYahoo Financeから取得して折れ線グラフを表示します（保存はしません。毎回取得し直します）。

## トラブルシューティング: ウイルス対策ソフトに「フィッシング」としてブロックされる

Norton（ノートン）などのセキュリティソフトは、`*.workers.dev`のような「誰でも無料で作れるランダムなサブドメイン」を、過去にフィッシング詐欺で悪用された実績があるパターンとして自動的に警戒し、**URL単位で**誤ってブロックすることがあります（このWorker自体は何も悪いことをしていません）。

症状: アプリの「株価を更新」「チャートを表示」「銘柄検索」を押しても反応がない／エラーになる。ブラウザで直接`https://<worker>.workers.dev/...`を開くと、セキュリティソフトの警告画面が出る。

Nortonでの対処手順（実際に解決できた手順）:

1. ブロック時に出るポップアップから「詳細を表示」→「**誤検出を報告する**」を送信する。
2. Nortonアプリを開く → **セキュリティ** → **履歴** で、ブロックされたURLの項目を開く（Norton Safe Webの判定レポートページが開く）。
3. そのレポートページの「**異議を送信する**」から誤検知の異議申し立てを行う。
4. 上記を行った後、あらためてブラウザで対象URL（`/quote?...`・`/search?...`など）に直接アクセスし、ブロックされずJSONが表示されるか確認する。

Nortonの判定はURL（パス・クエリ文字列）ごとに個別に行われるようで、`/quote`は許可されても`/search`は別途ブロックされる、というように**新しいパスを使うたびに再発する可能性があります**。友人の端末にもNorton等が入っている場合、同じ現象が起きたら同じ手順を試してください。

繰り返し発生して煩わしい場合の根本対策: 無料の`*.workers.dev`サブドメインをやめ、独自ドメイン（年間数百円〜）をCloudflare Workerのカスタムドメインとして割り当てると、この手の「いかにもランダムな文字列」への自動警戒に引っかかりにくくなります。

## データのバックアップについて

データは端末のブラウザにしか無いため、ブラウザのキャッシュ・データを消去すると失われます。バックアップ機能は今のところありません（必要であれば、開発者ツールの `localStorage.getItem("kabuNoteStocks_v1")` の中身をコピーしておく、といった方法があります）。

## 技術構成

- `index.html` / `style.css` / `app.js` — アプリ本体（フレームワーク不使用のバニラJS、Chart.jsのみCDNから読み込み）
- `worker/worker.js` — Yahoo Finance中継用のCloudflare Worker（サーバー側で取得してCORSヘッダーを付けて返すだけ。何も保存しない）
